1. Create `CNAME` file with your domain
2. Configure DNS records at your domain registrar:
   ```
   A Records:
   185.199.108.153
   185.199.109.153
   185.199.110.153
   185.199.111.153
   
   CNAME Record:
   www → Dev-moe-kyawaung.github.io
   ```
3. Update GitHub Pages settings → Custom domain
4. Enable HTTPS enforcement

### Cloudflare Setup
1. Add your domain to Cloudflare
2. Update nameservers at domain registrar
3. Configure DNS in Cloudflare:

   | Type | Name | Value | Proxy |
   |------|------|-------|-------|
   | A | @ | 185.199.108.153 | Proxied |
   | A | @ | 185.199.109.153 | Proxied |
   | A | @ | 185.199.110.153 | Proxied |
   | A | @ | 185.199.111.153 | Proxied |
   | CNAME | www | Dev-moe-kyawaung.github.io | Proxied |

4. SSL/TLS → Full (Strict)
5. Speed → Auto Minify → Enable HTML, CSS, JS
6. Speed → Brotli → Enable
7. Caching → Browser Cache TTL → 1 month
8. Rules → Page Rules:
   ```
   *dev-moe-kyawaung.github.io/Supreme-Portfolio-V5-Quantum-Edition/*
   Cache Level: Standard
   Edge Cache TTL: 1 month
   ```

## 9. 📄 GitHub Actions Workflow

### .github/workflows/deploy.yml
```yaml
name: Deploy to GitHub Pages

on:
  push:
    branches: [main, master]
  workflow_dispatch:

permissions:
  contents: read
  pages: write
  id-token: write

concurrency:
  group: "pages"
  cancel-in-progress: true

jobs:
  deploy:
    environment:
      name: github-pages
      url: ${{ steps.deployment.outputs.page_url }}
    runs-on: ubuntu-latest
    steps:
      - name: Checkout repository
        uses: actions/checkout@v4

      - name: Setup Pages
        uses: actions/configure-pages@v4

      - name: Upload artifact
        uses: actions/upload-pages-artifact@v3
        with:
          path: '.'

      - name: Deploy to GitHub Pages
        id: deployment
        uses: actions/deploy-pages@v4
```
